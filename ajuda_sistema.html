ℹ️ Atualização de Arquitetura

O sistema foi otimizado para garantir performance máxima em locais com baixa conectividade. A dependência direta do ERP Protheus durante o login foi removida.

1. Novo Fluxo de Acesso e Modalidades

Ao abrir o aplicativo, você deve selecionar entre duas modalidades principais de operação:

  • Interno Modo Offline: Ideal para inventários em locais sem qualquer sinal de internet. Os dados são salvos localmente no navegador (IndexedDB).
  • Supabase Modo Cloud: Recomendado para a maioria das auditorias. Permite sincronização em tempo real de fotos e dados com a nuvem GBR.

Nota: O login agora é centralizado. Você não precisa mais de uma conexão ativa com o servidor do Protheus para iniciar seu trabalho.

2. Por que mudamos? (Vantagens)

A remoção da "Modalidade Protheus" direta no login traz benefícios críticos para o campo:

  • Estabilidade 3G/4G: Sem quedas de sessão por instabilidade no link do ERP.
  • Performance: O carregamento de ativos é instantâneo, pois os dados residem em uma camada de alta performance (Supabase/Local).
  • Sincronização de Fotos: As fotos são enviadas em background, permitindo que você continue auditando sem esperar o upload terminar.
3. Configuração de Integração (Administradores)

Para que os dados auditados cheguem ao Protheus, o administrador deve configurar o ponto de integração:

  1. Acesse o Menu Administrativo.
  2. Vá em Módulo Protheus.
  3. Habilite a integração e insira a URL da API Protheus da sua unidade.

Aviso: Esta configuração é feita uma única vez por unidade/tenant.

4. Garantia e Integridade de Dados Técnicos

Mesmo com a mudança de fluxo, a integridade técnica com o ERP é 100% preservada:

  • Recnos Preservados: Os campos Sn1_recno e Sn3_recno são carregados e mantidos em cada registro.
  • Rastreabilidade: Cada alteração feita no aplicativo mantém o vínculo original com a tabela do SIGAATF, garantindo que o retorno dos dados ao Protheus seja preciso e sem duplicidades.
5. Painel Administrativo e Gestão de Dados

O ecossistema administrativo do GBR v24.50 é dividido em três pilares principais para garantir o controle total da operação:

A. Configurações Operacionais

  • Configurar Campos: Define quais informações (Descrição, Serial, etc.) o auditor pode editar.
  • Configurar QR Code: Personaliza os dados contidos nas etiquetas geradas pelo app.
  • Gestão de Acessos: Controle centralizado de usuários e perfis (ADMIN/AUDITOR).
  • Auto-Conferência: Agiliza o campo registrando o item imediatamente após a leitura.
  • Evidência Fotográfica: Torna a foto obrigatória em divergências ou novos itens.
  • Feedback do Scanner: Ajusta alertas sonoros e vibratórios do dispositivo.
  • Otimização de Energia: Modo Escuro e Economia de Bateria para longas jornadas.
  • Módulo Protheus: Configuração técnica para integração com o ERP Protheus via API.
  • Manual do Sistema: Acesso à documentação técnica interna em formato Markdown.

B. Gestão e Manutenção de Dados

  • Carga Expert: Importação massiva de ativos via planilhas Excel (.xlsx) ou CSV.
  • Sincronização Cloud: No modo Supabase, permite baixar e enviar dados para a nuvem.
  • Backups e Restauração: Geração de arquivos JSON locais para segurança e restauração rápida de estados anteriores.
  • Exportação XLS: Gera relatórios em Excel com o status atualizado de todo o inventário.
  • Limpeza Seletiva/Total: Ferramentas para apagar dados de unidades específicas ou resetar completamente o banco (Local + Nuvem).

C. Análise e Performance (Analytics)

  • Painel de Progresso: Visão detalhada do avanço por unidade e endereço.
  • Rendimento Global: Gráficos de produtividade diária da equipe de auditoria.
  • Mapa de Calor: Visualização geográfica da dispersão dos ativos (Geotagging).
6. Módulo de Gestão e Manutenção (Painel Administrativo)

Este módulo é o "coração" técnico do sistema, onde o administrador gerencia o ciclo de vida dos dados e a integridade da base. Abaixo, detalhamos as operações críticas:

A. Sincronização e Modalidades

  • Modalidade de Acesso: Permite alternar entre o Banco Interno (IndexedDB) para uso offline e o Banco Externo (Supabase) para colaboração em nuvem. Aviso: Mudar de modo altera a origem dos dados e o fluxo de login.
  • Sincronizar Nuvem: No modo Supabase, este comando baixa os dados mais recentes da nuvem para o dispositivo, garantindo que o auditor trabalhe com a base atualizada.
  • Baixar Dados da Nuvem: Realiza um download direto e forçado dos dados do Supabase, útil para auditorias de integridade ou recuperação de desastres.

B. Importação e Exportação

  • Carga Expert: Ferramenta de importação massiva. Aceita arquivos Excel (.xlsx) e CSV. O sistema processa automaticamente as colunas conforme o protocolo GBR v24, eliminando duplicidades e itens baixados irrelevantes.
  • Baixar Base de Dados (XLS): Exporta o estado atual do inventário (incluindo fotos e coordenadas GPS, se disponíveis) para um arquivo Excel formatado para auditoria.
  • Backup JSON (Local): Gera um arquivo de segurança contendo todos os dados armazenados localmente no navegador. Essencial antes de limpezas ou trocas de dispositivo.
  • Restaurar Backup: Permite carregar um arquivo JSON previamente gerado, restaurando o inventário para aquele ponto exato no tempo.

C. Rotinas de Limpeza (Purge)

  • Limpeza Seletiva: Permite escolher unidades de negócio ou filiais específicas para remover do dispositivo, liberando memória sem apagar todo o trabalho.
  • Limpeza Total (Local + Nuvem): O comando mais crítico do sistema. Apaga permanentemente todos os registros do dispositivo e do servidor Supabase. Requer confirmação dupla.

D. Gestão de Acessos e Usuários

  • Nome Completo: Nome de exibição do auditor nos relatórios e logs. (Ex: Glaucio Silva)
  • Username de Login: Identificador único para acesso ao sistema. (Ex: glaucio.silva)
  • Perfis de Acesso:
    - ADMIN: Acesso total a configurações e gestão.
    - MASTER: Gestão de usuários e dados de sua organização (Tenant).
    - AUDITOR: Acesso apenas à coleta de dados em campo.
  • Ativação Cloud: Opção para criar automaticamente o login no Supabase Auth durante o cadastro do usuário.

Dica de Persistência: Se os nomes dos usuários parecerem desatualizados, utilize a função "Sincronizar Nuvem" no modo Supabase para baixar as informações mais recentes do servidor.

Segurança: Sempre gere um Backup JSON antes de realizar operações de Limpeza ou Carga Expert.

Perguntas Frequentes

Posso trocar de modo (Interno para Supabase) no meio do trabalho?

Sim, mas recomendamos exportar um backup em JSON antes da troca para garantir que nenhum dado local seja sobrescrito pela base da nuvem.

O que acontece se eu ficar sem internet no modo Supabase?

O sistema continuará funcionando normalmente. As alterações ficarão em uma fila de sincronização e serão enviadas automaticamente assim que o sinal for restabelecido.

💡 Dica de Ouro

Sempre utilize o Modo Imersivo (Full Screen) durante a leitura de etiquetas para evitar toques acidentais nas barras de navegação do celular.
